## 为什么创建 Research Atlas？

**Research Atlas** 是一个可检索、可追溯官方来源、持续增长的高中生科研机会数据库。除了美国和全球的高中科研暑期项目，我们特别研究中国高校、科研院所、省级教育部门以及企业联合开展的青少年科研培养计划。

截至 **2026-11-10**，已整合 **75 条全球基础数据 + 75 条中国高校和科研机构专项承办轨道 = 150 条记录**。

> 注意：150 是数据库**记录 / 承办轨道数量**，不是 150 个互不相干的科研实习。全国计划不同大学的培养基地或分营会分别收录。往届项目出现于数据库不意味着目前仍开放报名。

### 科研项目分类

| 机器标记 | 中文 | 解释 |
| --- | --- | --- |
| **lab** | 真实实验室科研 | 在实验室研究环境参与项目 |
| **mentor** | 导师制研究 | 由高校科研人员或团队指导原创问题 |
| **structured** | 结构化科研训练 | 方法课程和研究型实践结合 |
| **exposure** | 短期科研体验 | 实验室参观、科普报告、科研体验；**不保证独立研究** |
| **community** | 竞赛或开放协作 | 独立研究竞赛、开源共同体等 |
| **admissions** | 特殊招生 / 贯通培养 | 高中阶段参与大学选拔，后续正式入学；**不是暑期科研实习** |
| **course** | 课程型夏校 | 授课和基础能力训练 |
| **commercial** | 商业科研指导 | 付费导师服务，必须单独评估价值 |

## 中国高校专项调查

中国的资源通常不是单个独立夏校网站，而是通过省级科协与教育系统、高校导师、中学推荐开展。本数据库采用以下层次：**全国母项目 → 省级实施 → 高校 / 科研机构承办轨道**。

已收录的重点方向（仍在扩展）：

- **最新补充的省级科研体系**：山西大学 2026、东北大学 2026、河北四所高校 2025、吉林两所高校 2025、中国科大和中科院合肥物质院 2026、北京青少年科技后备人才计划及北大 A 计划、甘肃飞天英才五家培养单位等。

- **中学生英才计划**：2026 年上海五所基地（复旦、上海交大、同济、华东师大、华东理工）；江苏六所基地（南京大学、东南大学、南京航空航天大学、南京理工大学、南京农业大学、南京师范大学）；湖北四所基地（武汉大学、华中科技大学、华中农业大学、华中师范大学）；重庆大学、大连理工大学，以及有其他年份官方证据的高校轨道。
- **青少年高校科学营**：2026 年上海、江苏、北京、浙江、重庆的高校分营。按短期科学体验收录，不把参观实验室包装成科研实习。
- **广州中学生科技特训营**：华南理工大学、暨南大学、中国科学院广州地区多个研究所等承办轨道。
- **高校企业联合研究**：腾讯—清华犀牛鸟中学科学人才培养计划。
- **大学特殊招生扩展路径**：清华丘成桐数学领军计划、北京大学数学英才班及物理卓越计划、中科大少年班及创新试点班、西安交通大学少年班。

**覆盖范围透明说明：** 中国专项数据目前涉及大陆 **16 / 31** 个省级行政区（含历史项目与短期科学营），其余地区是调查待办，不代表不存在项目。[查看全国地区覆盖与缺口](./data/CHINA_COVERAGE.md)。

### 本地开发

仅需 Node.js 22 或以上。没有 npm 安装步骤：

    git clone https://github.com/1998x-stack/High-School-Research-Programs.git
    cd High-School-Research-Programs
    node scripts/build.mjs --check
    node scripts/build.mjs
    node scripts/export.mjs
    node scripts/audit.mjs
    python3 scripts/export_sqlite.py
    python3 -m http.server 8000 --directory docs

然后访问 http://localhost:8000 。为避免浏览器本地文件访问限制，不要直接双击 HTML 文件。

### GitHub Pages 首次启用（仓库所有者执行一次）

站点文件和 CI 已提交，但 GitHub Pages 必须先在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。随后通过 **Actions → Deploy Research Atlas → Run workflow** 触发首次部署，或者再次提交相关文件。没有完成该操作之前，站点链接可能返回 404。

### 数据如何持续更新？

1. 贡献者找到新的**官方招生通知**，或发现现有资格/费用/时间有变。
2. 修改 data 目录中的原始记录，并保留当届年份、限制条件和原始链接。
3. 提交 Pull Request；校验程序检查记录 ID、必填字段、日期与 HTTPS 来源。
4. 合并到 main 后，GitHub Actions 自动重新生成网页检索索引并部署 GitHub Pages。

网站的内容会随仓库更新，但并不假装自动确认招生实时状态；**官方来源仍需人工核查**。

完整的格式要求与证据标准见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

### 数据使用限制与原则

- 优先引用学校、科研院所、政府主管部门、项目方官方网站。
- 不根据旧届次推导新一届仍开放。未知信息标注待核实。
- 免费项目也可能有交通、住宿、签证和个人生活费用。
- 独立招生、短期参访、实际研究工作是**不同类型的机会**。
- 记录数量不等于互不重复的项目数量，也不等于当前可申请名额。
- 本仓库不代表任何高校官方立场，不保证录取或签证结果。
- 任何新项目必须有可检查的来源。欢迎提交纠错、失效链接和遗漏信息。

## English overview

Research Atlas is an **open, community-maintained catalog for high-school research opportunities worldwide**. We index lab internships, mentored projects, science exposure camps, academic competitions, and early university admission pathways as **different categories**, each with source URLs, program year, eligibility notes and cost information.

The initial release includes **150 searchable records/tracks**, of which **75** are newly researched China-focused university/institute tracks. Some records are campuses or tracks of a shared umbrella program, not separate internships. The evidence baseline is **2026-11-10**. Historical listings are not proof of current availability.
